# 物业管理系统 BI 功能清单

> 依据 `doc/物业管理系统数据看板 - 数据字段清单.md`、`doc/indicators-api.md`、`doc/be-data-api.md` 整理。

---

## 一、页面层级总览

| 层级               | 内容                 | 说明                                                                     |
| ------------------ | -------------------- | ------------------------------------------------------------------------ |
| **一级页面** | 数据看板（首页总览） | 8 个模块卡片，每卡含 Hero 主指标 + 子指标                                |
| **二级页面** | 各看板下钻           | 概况 `overview` / 趋势 `trends` / 排行 `rank` / 异常 `exception` |

---

## 二、一级页面：首页 8 大模块卡片

| # | 模块                   | 接口                             | 统计口径（服务端固定）                    | 卡片展示字段                                                                   | 可下钻 |
| - | ---------------------- | -------------------------------- | ----------------------------------------- | ------------------------------------------------------------------------------ | ------ |
| 1 | **项目看板**     | `POST /community/communityMsg` | T-1 所在月份                              | 项目数量、管理面积、员工总数、客户数量、房屋套数、合同面积、收费面积、市拓面积 | ✔     |
| 2 | **收入看板**     | `POST /bill/statistics`        | 本月                                      | 收缴率、本期应收、实收本期、实收往期、实收来期                                 | ✔     |
| 3 | **租赁指标**     | `GET /data/1/rent/rentBasic`   | T-1（累计）                               | 可租资源面积、已租资源面积、时点出租率、累计应收金额、累计实收金额             | ✔     |
| 4 | **库存看板**     | `POST /store/statistics`       | T-1 月库存 + 近 7 天出入库                | 库存数量、库存金额、入库数量、出库数量、消耗数量                               | ✔     |
| 5 | **巡更看板**     | `POST /patrol/statistics`      | 近 7 天                                   | 任务完成率、总线路数、总点位数、总任务数、签到率                               | ✔     |
| 6 | **设备看板**     | `POST /equipment/statistics`   | 近 7 天（机构 13513912 及下属为近 15 天） | 巡检任务完成率、设备总数、报障设备数、巡检计划数、保养计划数                   | ✔     |
| 7 | **客户工单看板** | `POST /customer/statistics`    | 近 7 天（服务端自动展开子机构）           | 满意率、工单数、完成数、超时率、返工率                                         | ✔     |
| 8 | **品质看板**     | `POST /quality/statistics`     | 近 7 天                                   | 任务完成率、计划总数、完成数、及时数、及时率                                   | ✔     |

> 说明：8 个模块**均可进入二级详情页**，但区块不同：6 个业务模块为「趋势 / 排行榜 / 异常」；项目看板只有「占比分布」（业态 / 阶段 / 房屋状态）且不显示时间筛选；租赁看板为「收入趋势 / 排行榜 / 占比分布」（无异常块）。

| 项目阶段占比   |                                                                                                                                        |                                                                                                                                  |           |
| 房屋状态占比   |                                                                                                                                        |                                                                                                                                  |           |

> **实现状态（前端）**：三张占比图已在下钻页实现（复用 `RingChart`），接口未提供业态 / 阶段 / 房屋状态维度 → 当前为 **Mock**，UI 上标注口径提示；项目看板无趋势 / 排行 / 异常，下钻页不显示时间筛选。

### 2. 收入看板

| 功能           | 明细                                         | 状态                                          |
| -------------- | -------------------------------------------- | --------------------------------------------- |
| 应收概况       | 本期应收、本期已收、收缴率                   | ✔ 3 项提供（**本期欠费 ✘**、环比 ✘） |
| 清欠概况       | 期初往期欠费、本期调整欠费、本期清欠、清欠率 | ✘ **接口无欠费口径，整组缺失**         |
| 实收概况       | 实收往期、实收本期、实收来期                 | ✔ 3 项提供                                   |
| 实收总额       | 往期 + 本期 + 来期                           | △ 前端三者加总（环比 ✘）                    |
| 收入趋势       | 近 12 个月（应收 / 实收 / 收缴率）           | ✘                                            |
| 实收科目组占比 | 本月 / 上月 / 本年                           | ✘                                            |
| 欠收科目组占比 | 本月 / 上月 / 本年                           | ✘                                            |
| 欠收账龄占比   | 本月 / 上月 / 本年                           | ✘                                            |
| 清欠占比       | 本月 / 上月 / 本年                           | ✘                                            |
| 收缴率排行榜   | 区域榜、项目榜                               | ✘                                            |

> **实现状态（前端）**：收入下钻页已实现 —— 概况（应收 / 清欠 / 实收 / 实收总额，含环比）、收入趋势（近 12 月折线）、四类占比（实收科目组 / 欠收科目组 / 欠收账龄 / 清欠，随「本月 / 上月 / 本年」切换）、排行榜（区域榜 + 项目榜）、异常（收缴率低于 90%、连续 2 月下滑）。
> **Mock 标注**：欠费 / 清欠 / 科目组 / 账龄四类口径接口**明确未提供**，全部为 Mock（UI 上已标注）；概况在「本年」档按 APP 截图实际数据（应收 4,878.82 / 已收 202.97 / 欠费 4,675.85 / 收缴率 4.16%），「本月」档与首页 `bill/statistics` 自洽（应收 1,930.77 / 实收 1,860.44 / 收缴率 96.35%）。
